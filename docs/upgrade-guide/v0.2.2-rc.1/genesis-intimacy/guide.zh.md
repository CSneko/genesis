# 可选亲密状态需要兼容的读取器

[English](guide.md) | 中文

## 变更

保存“性与亲密”设置会为第三版 Genesis 情绪锚点添加可选的第一版 `intimacy` 投影。已有锚点仍可读取，不会初始化此功能。旧版严格情绪读取器会拒绝包含新增字段的锚点。停用功能保留保存的投影，不会使回滚兼容。Session 事件判别字段与生命身份保持不变。

## 迁移

1. 保存亲密设置前，为部署专用 `DSH_HOME` 中的生命主存储、写入备份和 Session 存储保留已校验副本。
2. 使用组合 Genesis 情绪与记忆的受支持 `dsh` 配置，在“插件 → Genesis → 性与亲密”中设置。仅在接受历史保留时保存；清除当前状态保留审计事件、Session 日志和备份。
3. 检查性欲从配置基准开始（通常为 0.5），重启同一配置后确认身份与设置保留。已初始化投影缺失或版本无效时会明确失败，不会创建另一生命。
4. 回滚旧版读取器前，停止写入方并恢复已验证的启用前备份组。不要手工移除字段或审计记录，也不要将停用或清除当前状态当成存储转换。
