# 临时记忆生成采用有界重试与跳过

[English](guide.md) | 中文

## 变更

Genesis 临时记忆每批自动尝试最多三次，可选生成仍失败时持久跳过。手动重试不能重新生成已跳过的批次。此前生成失败会停止来源并等待手动重试。旧的模型、JSON 和校验失败在启动后按新策略继续处理。来源对话与失败审计仍保留。恢复、存储与重要性结果不确定等问题仍明确停止。同一 Host 运行期间连续跳过三批后集中显示一条当前诊断，成功生成后清除，重启重置健康计数。

## 迁移

1. 升级前，如需保留待处理失败批次供后续分析，请保存相互匹配的 Genesis 临时存储与 Session 日志。
2. 可在 Genesis 插件的 `cordis.yml` 配置中设置 `temporaryMemory.maxAttempts` 和 `temporaryMemory.failureThreshold`，两者默认均为 `3`。
3. 打开设置 → 临时记忆查看当前诊断、搜索摘要和切换分页。修复报告的模型或凭据问题，下一批成功生成后会清除连续失败提示。参见[恢复与删除](../../../genesis/temporary-memory.zh.md)。
