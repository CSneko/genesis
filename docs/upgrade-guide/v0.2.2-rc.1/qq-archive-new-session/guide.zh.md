# QQ 归档后开启新会话

[English](guide.md) | 中文

## 变更

归档 QQ Session 此前会暂停入站回复，直到操作者恢复会话。现在下一条准入消息会为同一用户或群创建新 Session。生命数据保留历史绑定，最新绑定接收后续消息，重启后也如此。取消归档较早的 Session 不会重新选中它。主动发信不会替换已归档目标。

生命数据可为同一 QQ 路线保存多个历史 Session 绑定。要求每条路线只能有一个绑定的旧版读取器会拒绝这些记录。升级或降级前请保留已验证的备份。

## 迁移

1. 要停止接收消息，请在 QQ 设置中禁用连接或移除允许目标，不再通过归档其 Session 暂停接收。
2. 归档群聊或私聊 Session，再发送一条获准消息。确认新 Session 收到消息，而旧 Session 仍保持归档。
3. 降级前请连同 Session 和工作区数据恢复兼容的生命数据备份，不要手动修改绑定。
