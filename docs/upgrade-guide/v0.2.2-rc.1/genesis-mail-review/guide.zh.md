# Genesis 邮件审查

[English](guide.md) | 中文

## 变更

Genesis 邮箱使用知识库决策模型检查来信中的提示词注入，以及发件草稿中的私人身份信息和秘密。未审查的来信对角色隐藏。拦截邮件仍供操作者查看，从垃圾箱恢复不会放行。审查服务失败时拦截对应邮件。邮箱存储域从第一版迁移到第二版，已有记录从待审开始；已有对话内容保留。旧运行时拒绝第二版。升级前备份匹配的邮箱和生命状态，降级前先恢复该备份。

## 迁移

1. 使用邮件前配置**设置 → 知识库 → 决策模型**。支持已有提供方与 System One 路由，无需单独的邮件模型。
2. 通过 `pnpm dsh web` 重启。打开 **Genesis → 邮件**；后台收信和打开的页面按 `pollMs` 自动更新，默认一分钟。
3. 在**拦截邮件**查看被拒绝的来信或草稿。发件被拦截会返回工具错误；修正内容或决策模型后新建草稿。允许公众人物和公开企业地址。审查审计存储与删除见[邮件指南](../../../../packages/experimental/genesis-mail/README.zh.md)。
