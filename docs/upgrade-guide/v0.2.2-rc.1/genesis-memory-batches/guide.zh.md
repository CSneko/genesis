# Genesis 自动记忆批量评审

[English](guide.md) | 中文

## 变更

启用 Genesis `memory` 的部署默认每四个完整交流回合一起评审（`memory.batchTurns: 4`），不足时空闲三分钟后补评审（`memory.batchIdleMs: 180000`）。默认上下文窗口从四轮增至八轮。独立决策提示词分别考虑具体的日常经历与持久习惯；写入提示词和已保存的决策阈值保持原样。

私有、可忽略的 Session 回执记录已评审批次。首次启用时从已有完整回复之后开始，不回填历史。之后重新打开会话可恢复待处理交流。失败评审保留证据；进程在记录回执前退出时，已成功提交的生命改动仍保持幂等。旧运行时跳过该回执，继续采用自己的评审频率。

## 迁移

1. 使用原有支持的 `dsh` profile 和 Genesis 叠加层重启。已保存的模型路由和阈值无需调整。
2. 如需保留原有频率和上下文默认值，在 Genesis 插件配置中设置 `memory.batchTurns: 1` 和 `memory.windowTurns: 4`。两种模式下手动逐条回复生成均立即执行。
3. 启用批量模式后，完成四轮交流，或让不足一批的交流空闲三分钟。在记忆或知识库中查看最近评审；有效的无需更新判断也算完成评审。限制与失败恢复见[记忆行为与恢复](../../../genesis/memory.zh.md)。
