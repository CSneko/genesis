# 压缩后的手动记忆总览

[English](guide.md) | 中文

## 变更

Genesis“整个对话”记忆总览仅使用最近一次已提交的上下文压缩替换消息之后的用户与助手聊天。压缩前聊天和压缩摘要均不参与。已有记忆仅在全部来源属于该 Session 压缩后交流时参与；较早及混合来源记忆保留在存储中，不进入本次编辑范围。没有压缩时仍使用整个对话。

私有会话证据投影提升状态版本，从 Session 日志重建截断点，无需删除生命记忆或迁移 Session 格式。未产生替换消息的失败压缩不会推进截断点，重新打开会话后仍保留相同范围。

## 迁移

1. 重启原有启用 Genesis 的 `dsh` profile，并刷新浏览器加载新的范围说明，无需修改配置。
2. 对已经压缩的会话，继续交流后再选择“记忆 → 整个对话 → 总览整理当前对话”。压缩后尚无用户交流时，操作会提示继续对话，不读取较早记录。
3. 确认总览只考虑当前压缩后的交流段，原有较早记忆仍可在记忆页面查看。自动评审和单条回复手动生成继续使用各自的取证策略。
