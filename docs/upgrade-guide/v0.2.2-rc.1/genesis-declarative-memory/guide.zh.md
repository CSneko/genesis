# Genesis 陈述性记忆读取

[English](guide.md) | 中文

## 变更

`genesis_recall` 搜索返回 `genesis-recall-v1` 对象，替代字符串数组。消费者读取 `entries[].text`，`alreadyPresent` 表示当前读取仍在会话中。目录和浏览操作提供知识路径、人物关联与事件。非陈述性和临时存储保留原有含义。

生命记录增加可选的第一版 `organization` 元数据。当前读取器接受旧快照，旧的严格读取器拒绝升级后的记录。缺少组织信息的记录仍可检索：明确经历按事件读取，其余陈述性条目按 `unclassified` 读取，组织分类由正常写入模型或手动编辑设置。已有 Session 消息仍可读取；旧普通回忆结果没有可验证的读取凭据，允许重新读取。

## 迁移

1. 启动新版运行时前，停止旧写入器并保留完整生命存储与备份。启动时不创建独立的组织备份，已有组织备份继续执行身份检查和记忆删除清理。
2. 启动已有的 Genesis `dsh` 配置，打开“记忆 → 记忆”，浏览知识、人物、事件或未分类，通过“新增记忆”或“编辑记忆”填写目录与人物姓名。已有组织元数据和来源引用无需批处理即可读取。
3. 确认生命 ID、记忆正文与来源引用保持一致。自定义工具消费者须处理对象响应和两种读取层级，不将 `alreadyPresent` 误解为记忆缺失。`genesis_recall` 接受 `search`、`directory` 和 `browse`；记忆 Gateway 不提供批量分类操作。
4. 降级时停止写入器，通过配置的 Storage Domain 后端恢复完整、经校验的升级前状态。清单必须与所有配套组件一起保存；旧的严格读取器不能打开升级后的主记录。
