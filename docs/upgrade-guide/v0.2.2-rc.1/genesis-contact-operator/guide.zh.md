# Genesis 联系人操作者

[English](guide.md) | 中文

## 变更

Genesis → 联系人管理 QQ 与邮件共用的唯一操作者身份。QQ 和邮件设置不再提供独立的操作者账号输入。建立新的 QQ 关系时会创建或关联相同人物 ID 的联系人。启动时补齐已有关系，保留已保存的 QQ 操作者绑定，并将旧邮箱操作者地址并入对应联系人。操作者邮件仍须通过发件域名鉴权，仅匹配地址不能授予权限。

## 迁移

1. 停止现有 Genesis 写入进程，保留配套的生命、邮箱及会话存储备份，再用新构建重启原配置。生命身份和已有关系 ID 保持不变。不要让旧版写入已迁移的存储；回退时恢复备份。
2. 打开 Genesis → 联系人，核对补建人物和操作者勾选状态，在这里添加或修正操作者邮箱。选择另一个操作者会替换之前的标记。如果旧邮箱地址没有对应操作者联系人，启动会保留该地址并报告迁移未完成；建立操作者联系人后重试。
3. 保留设置 → 邮件中的收件认证服务配置。模型工具不能选择操作者或修改操作者邮箱。QQ 或经过鉴权的邮件使用操作者工具时，会重新检查当前联系人选择。
