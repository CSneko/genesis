# Genesis 记忆摘要与对话窗口

[English](guide.md) | 中文

## 变更

Genesis 记忆及其历史修订可在完整 `content` 之外包含可选的 `summary`。摘要提示词要求二十字以内，校验和手动编辑接受四十个 Unicode 码点以内。未包含该字段的已有记录仍可读取；保存摘要后，旧版严格读取器可能拒绝对应的生命状态。记忆列表优先显示已保存摘要，通过“查看全文”展示完整正文。

记忆决策与写入使用同一 Session 的近期交流，包括当前回复。`memory.windowTurns` 默认为四轮；输入预算不足时省略较早的交流。

## 迁移

1. 升级前停止 Genesis 写入进程，并保留经验证的生命存储备份。沿用已有 `DSH_HOME`、存储路由和身份。
2. 同时升级 Genesis 与其配套客户端 UI，无须批量转换或生成摘要；旧记忆保留完整正文。
3. 如需仅评估当前轮，在 Genesis 插件的 `memory` 配置内设置 `windowTurns: 1`，否则默认最多结合同一 Session 的四轮交流。
4. 打开记忆页面生成或修改摘要，并展开“查看全文”。确认重启后正文、来源、生命 ID 和出生时间保持完整。如需降级，使用升级前经验证的备份；不要通过删除无法读取的状态来创建替代生命。详见[记忆行为](../../../genesis/memory.zh.md)。
