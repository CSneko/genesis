# Genesis 写入租约协议

[English](guide.md) | 中文

## 变更

Genesis 在 `leasePath` 上使用内核锁，不再将文件存在视为已被占用。正常关闭和进程死亡都会自动释放所有权。锁文件会保留，不得删除或替换。旧版 Genesis 使用不同的加锁协议，不能与升级后的写入方同时操作同一份生命数据。

## 迁移

1. 启动升级后的写入方前，停止所有旧版 Genesis 进程。保留相同的 `DSH_HOME`、存储配置和 `leasePath`；已有的遗留锁文件可以保留。
2. 一起升级共享生命数据的所有写入方。POSIX 需要随包提供的原生 flock 绑定；Windows 使用独占内核文件句柄。使用支持内核锁的本地文件系统。
3. 启动平时使用的 `dsh` 配置，确认 Genesis 激活且生命 ID 和出生时间不变。第一个写入方持锁期间，第二个必须启动失败；第一个进程退出后，新的写入方应能直接启动，无需删除锁文件。
