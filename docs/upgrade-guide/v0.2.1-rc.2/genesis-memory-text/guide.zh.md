# Genesis 记忆文本输出

[English](guide.md) | 中文

## 变更

`genesis_recall` 返回当前记忆正文的 JSON 字符串数组，不再返回记忆对象；排除 ID、来源、置信度、时间戳、摘要和历史版本。读取对象字段的现有调用方需要修改。

注入的陈述性摘要、非陈述性正文与关联记忆改用普通文本行，不再包含 JSON 包装或记录元数据。内部来源、版本和管理界面仍可使用，生命存储不变。

## 迁移

1. 同时更新 Genesis 与客户端配套插件，重新构建运行资源并重启 Web 服务。
2. 自定义回忆调用方应直接读取字符串，不再访问 `result[i].content`、ID 或来源字段；完整记录通过已认证的记忆管理界面读取。
3. 移除对注入记忆节中 `entries`、`memories`、`omitted`、分数或 ID 的自定义解析；模型回忆改用相关关键词。
4. 回忆一个已知主题，确认工具仅返回当前正文；检查提示词记忆节为普通文本行，且“记忆”页面仍显示来源和历史。详见[记忆行为](../../../genesis/memory.zh.md)。
