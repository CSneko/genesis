# Genesis 动机与生命计划

[English](motivation.md) | 中文

## 摘要

主对话模型通过显式调用 `genesis_plan` 管理持久动机和跨会话计划。它自行决定何时建立长期承诺、指定可读 ID 并维护下一步行动。辅助模型不能创建或修改这些承诺；记忆、情绪、兴趣和主动交流仍使用各自的独立处理。

## 启用

工作区 Life 覆盖配置通过 `deliberation: {}` 启用计划。其他配置档可组合可选覆盖配置：

```sh
pnpm dsh --profile headless --patch packages/experimental/genesis/cordis.patch.yml --patch packages/experimental/genesis/cordis.deliberation.patch.yml --dump-config
```

配置转储仅验证组合；配置主模型后可将 `--dump-config` 替换为任务。计划本身不要求辅助写入模型或嵌入服务，提供的覆盖配置同时配置独立记忆。觉醒配置选用 Life 预设时，计划工具在该预设中属于先天工具，在普通预设中不可用。禁用审议会移除计划工具与上下文，但保留已存记录。

## 持久状态

| 记录 | 字段与含义 |
|---|---|
| 动机 | 具体行动倾向，包含可读品牌 ID、归因原因、强度、活动/暂停/结束状态和时间戳。 |
| 生命目标 | 长期承诺，包含可读品牌 ID、不可改写的内容与用户/自主/事件来源、原因、动机关联、优先级、状态、下一步行动、失败计数和变更历史。 |
| 决策 | 计划编辑或仅供交流的选择审计记录；记录计划不代表已经执行或完成。 |

审议状态使用既有原子生命存储与独立备份。ID、身份、时间戳和历史跨无关会话及重启恢复。已有 UUID 仍可读取和编辑，无需改名；新计划和动机 ID 由主模型指定。ID 包含 2–80 个 Unicode 字母或数字，分段间可使用连字符或下划线，并至少包含一个字母。UUID 和 24 位及以上的无语义十六进制标识会被拒绝；名称含义由模型负责。

动机强度保持在 [0, 1]，每次修改相对当前衰减强度的变化不超过 `deliberation.maxStrengthDelta`。`motivationHalfLifeMs` 控制从记录锚点开始的衰减，包含跨重启的经过时间。暂停和结束的动机不施加当前压力。这些是工程状态读数，不证明主观意识，也不是已确认事实。

## 请求决策

普通请求无需计划、计划更新或辅助模型接受检查。主模型可以在活跃对话中主动建立长期承诺，但不应每次回复都创建计划。旧 `requestMode` 值 `context-only`、`before-input` 和 `before-tools` 均使用此行为。执行授权、已学工具限制、沙箱策略、预算和停止控制仍然生效。

`genesis_plan` 使用 `action: list | create | update` 和 `kind: goal | motivation`。先列出记录以取得当前 `revision`、已有 ID 和有界历史；可选 `id`、`status` 和 `offset` 选择分页，使用 `nextOffset` 继续读取。目标更新需要原有不可改写的内容和来源，以及新的原因、优先级、状态、下一步行动和动机关联。动机更新需要内容、原因、状态和强度。创建和更新严格区分：更新不存在的 ID 会失败，不会创建另一份计划。

例如，主模型可以先创建动机 `understand-my-growth`，再创建自主目标 `review-capability-growth`，关联该动机并填写具体下一步行动。自主目标必须关联已有动机。目标支持暂停、恢复和放弃，终态目标不能重新开启。模型不能设置 `completed`、失败计数、时间戳或权限。改变方向需要单独创建目标，不能改写已有目标的内容或来源。

每次编辑检查显示的版本，并将实际会话/工具调用引用与变更历史一起提交。过期编辑、重复创建 ID 或无效状态不会改变原有状态。重复同一工具调用返回原收据，复用该调用写入不同字段则失败。可读 ID 也进入有界、已记录的生命上下文，使模型能识别未完成计划。

## 自主入口与结果

可信适配器或经过认证的操作者控制可为闲置角色对话调用 `ctx.get('genesisDeliberation').deliberate(agent, { key, sourceEventId }, signal)`。方法预留一次计划思考机会，并向主模型排入已记录的 `genesis-planning` 通知；辅助模型不选择目标或下一步行动。主模型可以通过工具修改承诺、执行获准行动，或保持计划不变。该机会不是用户任务或权限授予，也不安装任务定时器。

稳定键避免重复派发，包括重启后。预留不证明已送达；预留后崩溃或取消不会自动重发。使用新键请求其他机会前，应检查生命事件与会话日志。独立主动交流仍可以选择说话或等待，但校验器要求动机和目标变更为空。

只有可信应用能在独立核验关联执行成功后调用 `LifeCore.completeLifeGoal`。计划工具收据、无关工具成功或助手声明不能完成目标。已确认完成保留既有历史与成长记录要求。生命计划仍与 Harness 会话目标分离。

## 限制与扩展

`maxMotivations` 和 `maxGoals` 限制保留清单，包含终态目标。`contextChars` 限制完整的已记录审议上下文，`queryLimit` 和 `resultChars` 限制工具分页与历史。检索和推理限制仍适用于保留的独立交流判断。容量与校验失败保留已提交状态，存储写入结果不确定时停止依赖操作，直至可信重新加载。

无需密钥的 Loader 检查覆盖主模型工具调用、可读 ID、过期和无效编辑、重放、计划思考机会、权限隔离与重启连续性。真实模型主动规划质量仍需使用部署凭据评估。本功能不增加自主任务调度、反思或运行时自修改。
