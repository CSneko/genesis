# Genesis 临时记忆

[English](temporary-memory.md) | 中文

## 摘要

临时记忆是独立、会过期的会话解释，与[长期记忆](memory.zh.md)并存，保留来源 Session 和事件引用，不授予权限，也不把模型陈述变成已确认事实。

## 配置

使用受支持的源码工作区 Web 入口 `pnpm dsh web` 启动。打开**设置 → 临时记忆**，选择便宜的已注册提供者和模型，或兼容 OpenAI 的 Chat Completions 端点，填写空闲时长，启用并保存。功能初始关闭；页面先继承现有写入模型路线，供操作者改为更小的模型，不假定任何具体模型的价格或能力。

默认空闲 30 分钟，每分钟检查一次。总结端点可使用只写凭据 `GENESIS_TEMPORARY_API_KEY`，密钥与端点配置分别保存；已注册提供者使用既有凭据。重要性独立使用**知识库 → 决策模型**。修改这些设置不会改变长期记忆的写入或决策配置。同一页面提供当前摘要、过期时间、条数、省略提示、删除和显式重试。

## 触发与分批

来源会话空闲后可开始总结。在另一会话发送真实用户消息，也会将前一个普通生命会话标记为待总结。QQ 来源会话不会被其他会话的消息切换，而是在其未总结文字凑满一批且该 Agent 空闲时立即符合条件，因此持续聊天的 QQ 对话无需等到安静期也会产生摘要。不足一批的 QQ 尾部仍等待空闲间隔。正在运行的轮次先结束，维护再取得来源 Agent；维护期间到达的后续输入排队，并在维护任务恢复的 Agent 被释放前完成。总结不会生成聊天回复或 QQ 发送。

来源投影按事件顺序保留真实用户文字、可见模型文字和实际工具名称，排除工具参数、工具结果、注入上下文和隐藏推理。对这些文字字段按 Unicode 字符计数，包括标点；累计至少 1,000 字后，将跨过阈值的当前消息完整纳入本批。每批目标为约 100 字的中文摘要。空闲或切换触发时，最后不足一批的尾部也会总结。单条消息过大时明确拒绝，不截断原文；`temporaryMemory.inputChars` 限制完整推理输入，摘要响应另有字符限额。

恢复会发现尚无进度的已保存生命会话，包括这些会话中的较早消息；已有提交进度保持不变。部署限额约束跟踪会话、当前记录、排队工作、每轮处理会话数、每次批数及完整上下文输出；超限会报告失败，不静默丢弃证据。大量积压在后续定时维护中继续处理。

QQ 摘要用来源消息中的昵称或群名片称呼交谈对象；已验证操作者使用配置称呼。账号 ID 继续用于内部归属及权限范围，不作为人物的正文称呼。显示名称不证明身份或授予权限，同名不会合并发言者。此规则用于新生成的摘要。

## 重要性、共享与遗忘

每条成功创建的摘要记录一次重要性决定。普通提供者返回零到一的重要性，System One 路线提供概率。小于三分之一保留一天，小于三分之二保留两天，其余保留三天；过期时间从提交创建时刻计算。过期条目立即退出召回和上下文选择，维护会删除其当前存储记录，即使自动总结已关闭也会清理。

生命覆盖层选择的 `memorySharing: life` 允许所有参与的 Web 与 QQ 会话跨来源对话回忆未过期摘要；原受众字段继续保存，用于来源归属和切换策略。在 `memorySharing: conversation` 下，普通操作者会话之间共享摘要。QQ 私聊摘要限定为同一个人物；已显式绑定操作者的私聊摘要也可用于操作者 Web 会话。群聊摘要仅用于来源群。保存的受众不因昵称变化或绑定被删除而扩大。所有访问过滤先于召回和上下文选择。

下一次模型请求只收到新增和变化条目，以及对已过期、被删除或离开有界选择范围条目的明确撤销；未变化且仍保留的模块不重复注入。发送记录由 Session 投影重建，重启不会重置；被压缩移除的当前模块在需要时重新提供。`genesis_recall` 也可按关键词查找获准访问且未过期的临时正文，并明确标记解释性质与过期时间。

## 恢复与删除

独立的第一版 `genesis_temporary_memory` 域将每条摘要和对应会话进度原子发布。重要性请求中断时，已保存的待处理摘要仍保留；已完成并记入日志的重要性响应在重启后复用，不重新分类。若未记录已完成响应，则未知请求结果会停止该来源，直到操作者选择**重试失败的总结**；无法确认上次结果时，显式重试可能再次请求。失败或格式错误的响应不会成为记忆事实。存储写入结果未知时，停止依赖操作，直到验证并重新加载。

失败会在来源 Session 审计中保留实际、安全的模型诊断与失败阶段（恢复、摘要或重要性）。重试报告原始原因，不再替换为通用预算错误；设置采样也显示当前诊断。摘要出现 `max-tokens` 时，对应 `temporaryMemory.maxTokens`（默认 2048），可能需要降低辅助推理强度或提高这个明确的部署预算；连接、凭据和响应格式问题则须分别修正。失败批次不推进已提交进度。旧失败只有分类信息时，需在更新后的 Host 上重试一次以产生具体诊断。

**立即遗忘**删除当前摘要，不重置来源进度。原始对话与辅助审计仍保留在原 Session 日志中；过期和临时记忆删除不抹去日志，也不删除既有长期记忆。完整数据擦除仍需操作者执行现有 Session 与生命数据删除流程。生命状态备份不包含这个独立域，恢复时应保留匹配的临时存储和来源 Session 日志。生命身份不符、重复 ID、不兼容模式或无效过期时间都会明确失败。
