# @deepseek-ai/dsh-experimental-genesis-wallet

[English](README.md) | 中文

## 概述

可选 Genesis 钱包提供独立的人民币、美元余额，自定义商品、购买请求和带备注的流水。浏览器入口为**鲸元券**，模型学习的工具名为 `wallet`。源码工作区的 Genesis Web profile 包含此 bundle。确认购买只改变钱包状态，不通知或唤醒任何会话。

## 使用

通过受支持的源码入口 `pnpm dsh web` 启动，在左侧栏打开**鲸元券**。人民币和美元分别保存余额，页面名称不引入额外币种。修改余额直接覆盖当前值，不生成流水、旧值记录或模型通知。充值和转出需要备注并保存流水。已有会话证据和存储备份独立于钱包修改历史。

创建商品时填写名称、说明、价格、币种、规格以及可选的 HTTP(S) 购买链接。编辑、下架或删除目录商品不会改变订单快照。在操作者 Life 对话中让角色学习 `wallet`，即可查看余额和商品、按报价申请购买、查询订单，以及撤回本会话发起的请求。角色不能修改余额、创建自定义商品、确认订单或退款。QQ 群聊中，当前经过验证的发言者是已绑定操作者且 QQ 工具策略允许 `wallet` 时，可以调用；其他群成员不能沿用该权限。

有待确认请求时，侧栏图标显示红点，按 `pollMs` 刷新；打开页面不会消除红点。确认时检查当前币种余额，并一并提交扣款、订单与流水。待确认请求不冻结资金。重复确认不会重复扣款。拒绝和撤回不扣款；退款仅退回一次购买金额。确认不会产生消息、关注事件或自动模型请求；角色仅在主动查询钱包时获知当前状态。

余额、商品、订单和流水保存在版本一的 `genesis_wallet` 存储域中，绑定稳定的 Genesis 生命身份。已初始化状态缺失或生命归属不匹配时拒绝操作，不创建替代钱包。写入结果不确定时停止后续钱包操作，直至重新加载可信存储。删除钱包数据前应停止 Genesis，并与对应生命的集成归属一并删除；只删除钱包文件会阻止静默重新初始化。Session 日志与备份需要单独按生命周期删除。

### 内置淘宝来源

默认来源是[源头淘](https://yuantoutao.com/developers)，无需配置接口地址。不填 Key 时搜索其淘宝、天猫精选货架。在**鲸元券 → 商品**中可选填免费源头淘 API Key，以请求更广的实时结果；申请链接就在输入框旁。Key 供应、额度和上游数据时效由供应商负责。钱包不会自动注册账号或领取 Key。

Key 通过凭据服务保存到 `GENESIS_WALLET_TAOBAO_KEY`（`taobaoCredentialRef`），独立于钱包记录和 Session 上下文。同一引用也可解析环境凭据；删除已保存 Key 不会删除继承的环境凭据。凭据写入结果不确定时，内置查询会明确停止，直至重新加载可信凭据；余额与订单操作仍可使用。`taobaoEndpoint` 默认为 `https://mcp.yuantoutao.com/mcp`，允许部署方显式覆盖。

仅调用 `cps_smart_search` 和 `shelf_item` 两个只读操作，不挂载上游订单、支付或履约工具。查询限定淘宝、天猫，并转换供应商的整数人民币分价格。支持含 `id` 的淘宝天猫商品链接，以及源头淘 `/go/tb/<id>`、`/p/tb/<id>` 链接。链接查询读取已收录货架，未收录商品和短链接可能需要改用关键词搜索。价格是来源报价，不代表库存已核实或平台结账价有保证。供应商购买链接可能包含推广归因，钱包不会添加归因标识。

### 自定义信息适配器

若需覆盖内置来源，在 `genesis-wallet` 插件行中将 `productEndpoint` 配置为操作者控制的 HTTP(S) JSON 适配器地址。插件向固定地址发起 GET 请求，参数为 `query=<关键词>` 或 `url=<商品链接>`。模型提供的网址只作为查询数据，插件不会直接抓取该地址，并拒绝重定向。适配器需要 Bearer token 时，将 `credentialRef` 指向已有凭据引用；凭据不会进入商品记录或模型结果。

适配器返回 `{ "items": [...] }`，每项必须包含 `title`、`description`、`price`、`currency`、`url`、`specification`、`available` 和 `source: "taobao"`。价格使用整数分，3500 表示 35.00 人民币或美元。响应受 `timeoutMs`、`maxResponseBytes` 和 `pageSize` 限制。查询只读取信息，操作者可将候选项导入可编辑目录。模型的 `import` 操作会重新查询并选择 `index`（默认零）；来源链接和规格相同时复用现有目录商品，保留人工编辑。提交 `buy` 前应核对导入后的报价。

自定义适配器负责上游淘宝 API 账号、授权和字段转换。自定义来源凭据使用 `credentialRef`，不会发送给内置来源。商品文本始终是不可信数据，不能授予权限。

<a id="implementation"></a>
## 实现

<details>
<summary>存储、授权与资源归属</summary>

`cordis.patch.yml` 在 Genesis 旁挂载可选钱包服务，禁用此 bundle 不改变普通 Harness 行为。单一串行整体写入负责余额、商品快照、订单转换和流水凭据。实际 Session 与工具调用 ID 用于购买申请去重；内容不同的重放被拒绝。操作者写入检查展示版本，重复的过期转出不能再次生效。完整状态和完整模型结果分别受可配置容量限制。钱包查询先取消并排空，再释放存储。

`pageSize`、`maxRecords`、`maxStateChars`、`resultChars`、`pollMs`、`timeoutMs` 和 `maxResponseBytes` 控制部署限制。`lifePreset` 指定允许的 preset。模型执行还要求操作者 Life 会话；QQ 按当前经过验证的发言者和会话路由检查身份，不把群成员身份视为操作者身份。现有学习、沙箱和工具守卫继续生效。认证操作者 Remote 负责余额修改、目录管理与确认，不向模型工具暴露这些操作。

</details>

<a id="model-experience"></a>
## 模型体验

`wallet` 工具结构通过普通 Genesis 工具学习机制提供。结果明确标注币种，使用整数分。列表和来源响应均有限制，购买请求保留准确的商品快照。钱包数据不自动注入提示词。工具结果进入已有 Session 日志；操作者修改余额和确认购买不会添加模型上下文或发起模型工作。`purchased` 表示钱包中的购买已完成，不授予工具权限，也不证明运行时能力已可用。

<a id="known-limitations-and-deferred-work"></a>
## 已知限制与后续工作

钱包不执行真实支付或平台下单，不提供换汇、物流跟踪或库存冻结。内置来源无 Key 可搜索精选货架，提供供应商 Key 可请求实时搜索；不保证覆盖淘宝全网或每个商品链接。供应商凭据、限制与可用性仍是外部依赖。保留的钱包历史有明确容量限制，尚未实现自动归档。钱包归属于单个生命；普通 QQ 发言者即使获得群级工具授权，也不能访问。已绑定操作者可由自己当前的群消息触发调用，较早的操作者消息和引用身份不能向后续发言者授予权限。
