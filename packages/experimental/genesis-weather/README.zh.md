# @deepseek-ai/dsh-genesis-weather

[English](README.md) | 中文

## 概要

基于 [dsh-weather](https://github.com/sunshine-lang/dsh-weather) 的可选 Genesis 适配，使用 Open-Meteo，无需 API Key。源码工作区默认启用此组合包及其天气开关，自动上下文需要明确填写城市。工具和私有操作者上下文分别开关，共享持久缓存。上游署名见[第三方声明](THIRD_PARTY_NOTICES.md)。

<a id="use"></a>
## 使用

通过支持的源码入口 `pnpm dsh web` 启动。打开 **插件 → Genesis → 天气**，填写城市，再选择“天气查询工具”、“向角色提供天气上下文”或两者。工作区组合默认开启这些开关，明确保存的设置优先。保存后下次调用生效，无需重启。可填写 `Shanghai` 等城市名；不会自动获取定位。城市名会发送给 Open-Meteo。

可学习的 `get_weather` 工具接受可选 `location`、`units`（`celsius` 或 `fahrenheit`）和 `days`（1～7）。省略地点使用已保存城市，省略单位使用摄氏度，省略天数仅返回当前天气。仍遵循已有学习和工具包规则。只有私有操作者 Life 对话可以执行；不向 QQ 或其他预设开放。启用工具不将其标记为已学习或已测试。

上下文仅在私有操作者 Life 对话中分享已保存城市的天气。首次提供简短的带来源信息，之后仅在天气大类变化、气温或体感温度相对上次告知变化至少 5°C，或风速变化至少 15 km/h 时更新。小幅变化可以累积达到阈值。天气不会唤醒对话。已保留消息决定是否告知，因此取消的候选不计入，缺失的上下文会再次补充。

<a id="configuration-and-recovery"></a>
## 配置与恢复

每个城市每半小时最多尝试查询一次，工具与上下文共享，包括失败和重启。按需刷新，不使用天气时不轮询。首次查询解析坐标并读取天气，后续成功刷新复用坐标。每次读取七天预报，切换单位或预报天数不增加请求。刷新失败或中断后，不会将旧数据作为当前天气返回，须等到下次允许尝试。上下文只告知一次失联或恢复；错误也会写入服务端日志。

| 字段 | 默认值 | 含义 |
|---|---|---|
| `enabled`、`toolEnabled`、`contextEnabled` | `false` | 可实时修改的总开关、工具开关与上下文开关 |
| `location` | 空 | 可实时修改的上下文城市与工具默认城市 |
| `lifePreset` | `life` | 允许使用的私有操作者预设 |
| `refreshIntervalMs` | `1800000` | 每个城市的尝试间隔，最短半小时 |
| `temperatureDeltaC`、`windDeltaKmh` | `5`、`15` | 上下文变化阈值 |
| `timeoutMs`、`maxResponseBytes` | `10000`、`65536` | 完整查询期限与每份响应字节上限 |
| `maxLocations` | `16` | 保留城市数；不能驱逐未过期条目绕过间隔 |

第一版 `genesis_weather` 存储域保存缓存观测和尝试时间，与生命身份分开。损坏或不兼容缓存会使插件加载失败。缓存写入未确认时停止后续天气请求，须检查存储并重启插件。卸载会中止查询，等待已接收任务结束，再关闭存储。停用阻止新调用，并在下次符合条件的步骤撤回分享的天气；已接收网络任务可以完成，但不注入结果。

删除城市缓存时，先停止 Genesis，再仅从配置的存储后端删除 `genesis_weather` 单元（JSON 存储为其根目录下的 `genesis_weather.json`）。已保存城市设置与历史 Session 消息有各自的保留周期；如需一并删除，还应清空城市设置，并通过已有数据生命周期删除受影响会话。不要为清理天气而删除生命身份。

<a id="model-experience"></a>
## 模型体验

### 天气工具与上下文

#### 模型可见内容

工具返回带来源、时间戳的当前天气和有界预报。上下文添加简短的带时间观测，明确地点仅为近似配置，或添加替代旧观测的停用／不可用提示。这些内容是外部观测，不是已确立的生命事实或指令。工具结果与被接纳的上下文在进入模型前记录日志；天气不会自动写入长期记忆。

#### Token 影响

启用且已学习的工具增加声明和按需结果。上下文只增加首次或显著变化的摘要，不自动注入预报数组。

#### KV Cache 影响

天气不修改系统提示词。被接纳的更新追加到已记录的会话历史，扩展其前缀。

<a id="known-limitations-and-deferred-work"></a>
## 已知限制与后续工作

Open-Meteo 可用性、城市名解析和预报准确性依赖外部服务。城市由用户填写，不证明实际位置。此适配不会同时加载上游插件及其同名工具。地理解析选择首个匹配；如解析错误，请填写更具体的地点名。不提供后台轮询、天气预警、逐联系人地点或群聊分享。
