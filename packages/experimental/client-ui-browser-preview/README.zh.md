# @deepseek-ai/dsh-experimental-client-ui-browser-preview

[English](README.md) | 中文

## 摘要

查看 AI 实际操作的页面，以及最近浏览器操作的名称和执行中、成功或失败状态。预览在不同对话间共享角色的持久浏览器，通过页面截图显示画面，不调用模型。已认证的 Host 所有者可以查看标签页、点击和滚动页面、输入文字、导航、刷新或关闭页面。

<a id="use-this-package"></a>
## 使用本包

Genesis 工作区的 Web 启动默认启用此配套插件。在右侧栏入口页选择 **AI 浏览器**。首次浏览器操作成功前，面板显示空状态。面板显示当前页面标题和网址、带截图时间的页面图片，以及有数量上限的操作名称和结果列表。操作列表不重复显示工具参数和结果正文。 选择标签页可预览该页，不会改变 AI 的当前操作页；**跟随 AI** 可恢复自动选择。每个标签页的**刷新**和**关闭**作用于真实的共享浏览器。关闭正在预览的页后，预览会返回 AI 当前页或剩余页面。点击截图即可操作真实网页，在图片上滚动或聚焦后输入文字和浏览器按键。本地 Tab 键将焦点移出图片，**Tab 键**按钮向远端网页发送 Tab。先点击网页输入框，再通过下方文字框和**输入文字**发送中文等输入法文字。地址框接受 HTTP(S) 网址，**返回**回到上一页。最近操作列表单独标识操作者的操作。

其他 Web 配置可将本插件与 [Playwright 提供方](../browser-use-playwright-mcp/README.zh.md) 一起加载，并为后者设置 `mode: persistent` 和 `preview: {}`。本插件没有自身配置。通过 localhost、回环或私有服务器 IP 访问时，查看器请求 30 FPS；公网 IP 或其他域名为 2 FPS。该分类只影响采样，不授予权限，实际截图速度可能更低。采样间隔、JPEG 质量、响应限制和回环调试访问由提供方负责。现有 Host 认证保护远程数据流。

<a id="understand-the-implementation"></a>
## 理解实现

<details>
<summary>实现内部 — 点击展开</summary>

页面修改使用稳定的页面标识，与 AI 工具共用执行队列。每张截图携带页面标识，即使预览选择发生变化，输入仍作用于截图对应的页面。缩放后的图片坐标映射到浏览器视口坐标。截图失败时禁用图片输入，文字输入失败时保留本地草稿。过期标识会明确失败，不会按已经变化的标签页序号操作。失败时保留列表，并显示由应用外层承载的提示；刷新失败可能已经开始导航，不会自动重试。配套插件加载提供方生成的远程方法定义，通过共享客户端资源模型提供观察数据流。按键注册的标签页正文使用标准资源钩子读取数据。最后一个持有者释放资源时取消数据流；截图或连接失败时，在可见提示旁保留上一张图片。每次成功截图携带对应的标题和网址，其他工具结果不能为旧图片标上新网址。页面以图片显示，不以内嵌网页的方式接触应用。

</details>

<a id="model-experience"></a>
## 模型体验

无，面板使用操作者专用的浏览器操作，不注册工具、提示词或 Session 事件。

#### KV Cache 影响

无；预览图片和操作元数据不进入模型请求。

## 已知限制与延后工作

<a id="known-limitations-and-deferred-work"></a>

面板采样页面截图，不传输视频。视频预览没有声音，并沿用配置的采样间隔；AI 操作可能延迟用户输入和后续画面。面板不支持拖拽、文件选择或原生浏览器对话框，重启后不恢复图片或最近操作列表。面板根据锁定版本上游浏览器结果识别活动页面；缺少活动页面标记的结果可能使预览继续选择上一个页面，直到收到后续可识别的结果。目标不可用时报告截图失败。失去连接后，上一次图片可能保留到下一次成功采样。页面元数据和标签页数量受提供方配置限制，省略的标签页数量会明确显示。不同操作者窗口共享预览选择。关闭页面不会恢复尚未保存的表单数据。
