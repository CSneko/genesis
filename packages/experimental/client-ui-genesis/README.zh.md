# @deepseek-ai/dsh-experimental-client-ui-genesis

[English](README.md) | 中文

**Genesis → 邮件**自动更新分页邮件元数据和安全的文字预览，包括仅操作者可见的拦截邮件，与角色是否已读分别记录。**设置 → 邮件**管理账号凭据、不限／地址／域名收件人范围、主动发信和操作者邮件认证，详见[邮件指南](../genesis-mail/README.zh.md)。从垃圾箱删除本地副本会保留不含正文的去重回执，服务器邮件、Session 日志、记忆和备份分别管理。

## 概述

“设置 → 破甲”提供可选的生命行动指导开关，默认关闭。保存后从生命模式的下一次模型请求生效，包括 QQ，并在独立操作者偏好中持久保存，不受启动配置覆盖层限制。它鼓励直接回答、减少重复确认，同时保留角色选择和执行权限。保存失败保留草稿并显示原因；修订过期时需重新加载已保存设置。参见[破甲行为](../genesis/README.zh.md#配置)。

左侧边栏的 Genesis 与插件、自动化任务并列，集中提供生命信息、委派任务、记忆、性格、情绪、关系、目标、文字与发件记录。知识库、工具包、QQ 和 Minecraft 连接及主动发送策略仍在设置中。密钥使用既有凭据库，生命模式会话共享单一生命与记忆，普通预设保持隔离。“初始化生命”由用户在新对话界面或 Genesis 概览主动点击，命名后进入首次生命对话，成功完成后按钮消失。“不再出现”会持久关闭自动配置提醒，不新增网络监听端口。

设置 → 睡眠编辑作息和唤醒控制；Genesis → 念头管理私有认知。Life 会话显示当前睡眠状态。参见[睡眠](../../../docs/genesis/sleep.zh.md)。

睡眠横幅使用轻量作息接口；打开会话时不会订阅完整生命状态检查。

设置 → 语音合成配置可选的 [CosyVoice 工具](../genesis-speech/README.zh.md)，包括模型、接口和自定义音色 ID。

语音工具结果为新生成的本地 WAV 附件显示播放器与下载入口；AI 选择的语速和表达指令保留在日志结果中。

## 使用

模型配置统一为三个入口：LLM 默认复用 DSH，判断功能继承知识库决策路由，嵌入模型可选。各功能保留自定义，已有配置继续生效。未配置嵌入时，Markdown 记忆内容使用有界文本检索，写入仍保留来源引用。模型设置提供云端配置和明确点击的本地快速部署。本地运行时支持范围、下载来源、生命周期和限制见[模型配置](../../../docs/genesis/memory.zh.md)。

Genesis → 联系人可搜索称呼、QQ 号、邮箱和其他账号。可添加或编辑称呼、QQ、多个邮箱、其他“类型=账号”及备注；QQ 在创建后固定，因为它决定与关系共用的人物 ID。删除前会请求确认，并保留人物关系。保存失败会保留编辑草稿。勾选操作者会替换之前的标记，QQ 和邮件共用该选择。建立有意义的 QQ 关系时会自动创建联系人，已有关系在启动时补齐。AI 通过 `genesis_contacts` 使用同一份持久记录，详见[联系人行为](../genesis/README.zh.md#use)。

将本包 `cordis.patch.yml` 与 [Genesis 核心覆盖配置](../genesis/README.zh.md) 一同应用于具有预设注册表的 Web 或桌面配置，启动前重新构建浏览器包。[首次唤醒教程](../../../docs/genesis/awakening.zh.md)启用命名与首次问候。“生命信息”负责命名、身份和成长，“知识库”负责决策/写入/嵌入配置，并保存“自动重试次数”，默认额外重试三次，详见[重试行为](../../../docs/genesis/memory.zh.md)。“记忆”按时间从新到旧分页浏览全部记忆，并负责文本搜索、新增、编辑、删除和分类转换，展示经历时间、关联经历 ID 与可展开的以往认识，说明记忆如何形成和变化。可选生命预设成为部署默认值，已有用户默认选择优先。

启用[兴趣](../../../docs/genesis/interest.zh.md)后，“生命信息”还展示当前推断阶段、来源 ID 和有界变化历史。此页面不编辑兴趣。

“记忆”还提供持久化的自动巩固开关、立即执行、最近具体错误，以及习惯情境、响应和证据。预算与取消规则见[空闲巩固](../../../docs/genesis/memory.zh.md#automatic-habits-and-idle-consolidation)。

“Genesis → 情绪”展示九项即时反应、二维心境和独立心理需求、事件解释及有归属的有界历史。“Genesis → 关系”管理五项单操作者估计，分别标明证据置信度或明确人工设置，支持带原因的修订检查编辑。编辑器支持填写原因后手动调整、暂停自动评估，以及配置情绪、自然恢复及关系变化共用的敏感度。编辑检查修订并跨重启保存；写入失败保留草稿，成功关闭弹窗后仍有独立提示。参见[情绪管理](../../../docs/genesis/emotion.zh.md#operator-management)。 情绪设置编辑器还可保存停机计时策略和即时情绪、心境的两个耦合增益，并提供本地化行为说明。

“设置 → 主动消息设置”通过所属已认证 Remote 保存启停、目标会话、定时和投递限制。“Genesis → 发件记录”展示采样时的渠道可用性、最近确认的助手消息及有界触发、决策、回执历史，并标明待发送和不确定结果。设置保存失败保留草稿，详见[主动消息](../../../docs/genesis/social.zh.md)。

“Genesis → 委派任务”通过任务所属的已认证只读 Remote 分页读取有界结果，分别展示投递确认、执行状态、后台活动和轮次数。证据缺失或不可读时明确标为不可用。“打开会话”复用既有工作区导航查看结果及操作者执行控制；页面不创建、恢复或重试工作，不轮询、不唤醒冷 Agent。详见[工作区任务](../../../docs/genesis/tasks.zh.md)。

设置 → 工具包支持新建、重命名、移除分组，编辑准确工具名或前缀规则，并区分已学会成员与当前可用工具。空包和没有已学会成员的包仍可编辑，但不会告诉 AI。保存失败保留草稿，过期修订被拒绝，结果由外壳 Toast 提示；重新载入已保存配置会显式丢弃草稿。参见[工具包行为](../genesis/README.zh.md#toolkits)。

已完成回复的“记忆”弹窗还提供“整个对话 → 总览整理当前对话”，由写入模型结合完整聊天与所有会话关联记忆决定保留与变更，长证据先分段读取，再统一保存完整规划。筛选、预算和原子恢复见[会话记忆行为](../../../docs/genesis/memory.zh.md)。

记忆列表优先显示已有短摘要，提供“查看全文”、仅修改摘要和独立生成摘要。操作失败保留原文与草稿；摘要修改保留来源、归属、置信度和习惯。详见[简短摘要](../../../docs/genesis/memory.zh.md)。

“记忆”提供多选与手动整理，可归纳为一条或多条认识，成功后原子替换原始记录，失败时保留选择。生命预设包含内置[时间感知](../../context/time-context/README.zh.md)，提供已记录的时间读数与浏览器时区提示，见[整理选中记忆](../../../docs/genesis/memory.zh.md#selected-memory-organization)。

记忆页面提供可展开的操作者身份表单。保存时会安全替换现有记忆中的旧角色称呼，冲突会保留草稿。直接编辑和转换不新增历史。编辑器保留稳定日期标记，角色回忆时保留重要准确日期，普通经历相对显示，详见[身份与记忆时间](../../../docs/genesis/memory.zh.md)。

独立的 [Minecraft 分区](../genesis-minecraft/README.zh.md)配置访问权限、独立模型与监测，提供停止和断开控制。AI 在当前会话中通过 `minecraft_connect` 自行选择连接信息。实时状态订阅仅在资源打开时运行；关闭面板后仍继续游戏。

设置 → 临时记忆可配置独立的小总结模型、可选只写端点密钥与空闲时长，并提供过期预览、立即遗忘和失败来源重试。参见[临时记忆](../../../docs/genesis/temporary-memory.zh.md)。

可选的[视频工具包](../genesis-video/README.zh.md)生成 `*.genesis-remotion.html` 文件。其专用右侧栏查看器直接播放已保存的 Remotion 合成，支持拖动进度、音量与全屏；“在浏览器中打开”显示同一个隔离 Player。修改源码后，重新构建预览并重新载入文件即可查看。共享文件读取器负责鉴权、大小限制与刷新。关闭视图会释放 Blob URL，隐藏时暂停播放。

内置的[智能体伙伴设置](../genesis-companion/README.zh.md)按需启用内部 AstrBot 连接，配置独立作息，并提供手动交流、唤醒和停止控制。来源链接打开唯一持久伙伴 Session，手动交流和跨会话工具共享此会话。有界内部历史与带归属的关系认识独立于 QQ。刷新读取当前进度，不启动模型。

设置 → 浏览器通过共享的暂存配置表单编辑服务器侧 Chrome 调试地址。保存值在重启后保留，共享浏览器提供方重启时使用新地址；当前连接保持原地址。无效或过期的保存保留草稿。保存不测试连通性。参见[浏览器配置](../../../docs/genesis/README.zh.md#浏览器操作)。

Genesis → 情绪在即时感受、心境和需求之外显示独立的无聊读数，说明活动投入与孤独的区别；既有读数与编辑器保留各自字段。

## 实现

源码工作区的生命预设包含独立的自动压缩后端。插件挂载所属包生成的 Remote，注册 `genesis` 资源提供方并贡献本地化主页分区和配置页面和参与生命模式会话的已完成回复上的手动记忆入口。端点编辑通过带版本检查的生命配置存储保存，密钥使用既有凭据库，不进入配置或记忆。设置失败时显示受影响的操作和具体原因，包括 HTTP 状态码、校验字段或连接错误码，不显示密码原文或服务端响应正文。记忆和情绪设置显示最近已评估轮次及完成时间，包括无需变化的结果；Jev 决策还显示更新概率与本次阈值。聊天和知识库中的记忆失败显示失败阶段和安全诊断，重试错误保留自身原因，新失败轮次会重置重试提示。保存失败时保留草稿；刷新后点击“重新载入配置”可载入最新已接受的值。共享资源模型负责已读取数据，并在失败后保留旧值。凭据/设置/服务变化、对话运行状态变化、用户刷新与重连会请求新样本，普通 Genesis 状态资源不运行轮询定时器；资源中止会取消 RPC 并释放刷新监听器。

Genesis → 性格与说话风格分组展示长期自我倾向及过程类的说话、行为习惯。专用有界读取先筛选这些条目，不受无关记忆预览挤占。添加、编辑、转换和删除复用现有带版本检查的记忆操作与编辑器，写入被拒绝后保留草稿。此页面不调用模型，也不提供特质分数控件。

角色和记忆指令由主机生命插件负责。本配套插件通过既有 Session API 创建首次会话，请求主机加入已记录的内置唤醒。提供方检查会准备已配置路由，端点检查通过模型列表验证认证，嵌入测试执行一次请求。记忆浏览、文本搜索和直接增删改不执行推理。每条回复的手动生成使用原始对话证据和独立写入模型，跳过决策模型并强制所选分类，同时保留自动评估。版本检查、来源与重试行为见[记忆管理](../../../docs/genesis/memory.zh.md)。

Genesis → 她的记录通过已认证的记录 Remote 浏览、搜索、读取、编辑和删除角色文字，并管理类型。共享按需资源在失败后保留数据，捕获的草稿与版本检查保护编辑；删除、归属与恢复见[文字记录](../../../docs/genesis/records.zh.md)。

<a id="model-experience"></a>
## 模型体验

本页面通过有界 Host 操作管理 Genesis。QQ 提示词编辑影响后续带日志的 QQ 上下文，记忆预览本身不会发送给聊天模型。

#### KV 缓存影响

刷新仅读取主机状态，不追加对话事件或调用推理模型。接受的情绪调整与恢复设置影响后续已记录的生命上下文，暂停情绪评估会停止其辅助调用；相关模型影响由[情绪](../../../docs/genesis/emotion.zh.md)定义。

## 已知限制与后续工作

<a id="known-limitations-and-deferred-work"></a>

- 此视图按需采样，仅在唤醒模式提供一次性命名，不替换身份、不确认记忆、不编辑权限，也不持续轮询。
- 返回预算可能省略预览，数量与省略提示会明确区分；历史非活动会话的工具不会作为实时能力展示。
