# @deepseek-ai/dsh-experimental-genesis-mcp

[English](README.md) | 中文

## 概要

打开 **设置 → MCP 服务**，浏览官方 MCP Registry，进入服务详情并点击 **安装**。只有发布者声明需要参数时才须填写。保存后的服务自动连接，重启后保留。也支持自定义远程端点和本地命令。安装由经过身份验证的操作者执行，角色没有安装服务的模型工具。

<a id="use"></a>
## 使用

源码工作区 Genesis Web profile 包含此组合包。通过支持的应用入口 `pnpm dsh web` 启动，Genesis 浏览器配套插件提供设置页面。其他 Web 组合可以在 Genesis 及其浏览器配套插件旁添加此组合包，并提供已有的全局 MCP 管理器、Settings 和凭据服务。

发现页面列出发布者提供的说明和支持的连接方式。详情页优先选择 Streamable HTTP 端点，否则提供支持的、固定版本的 npm 或 PyPI 软件包。安装会保存连接并启动，无需另行启用。必填项直接显示，可选项收在“可选设置”中。本地安装使用 Genesis 服务器上已有的 `npx` 或 `uvx` 下载并执行软件。点击安装前查看显示的软件包。目录收录不验证安全性、可用性或价格。

已添加页面展示实际连接状态和当前注册的工具名，正在连接与已连接分开显示。操作者配置的条目可以停用、重连或移除；插件自带条目仍由所属插件管理。移除继承条目会恢复其继承配置，若要保持关闭请停用。自定义远程服务接受地址、可选 bearer token 和高级请求头。本地服务接受程序、JSON 参数数组和 JSON 环境变量映射。这些自定义操作只新增条目，替换已有服务需要移除后重新添加。

每个已启用的服务会自动在“设置 → 工具包”提供一个只读分组，成员随对应 MCP 命名空间的工具变化。停用或移除服务后，待工具清理完成再撤下分组；重新启用使用相同分组 ID。手动分组保持原值，安装不会自动学习或激活工具，也不授予 QQ 访问权限。

<a id="configuration-and-recovery"></a>
## 配置与恢复

`registryUrl` 选择兼容官方 Registry 的 API，`managerEntry` 指向已有 MCP 管理器的 profile 行。目录响应、缓存、分页、工具发现上下文和完整 RPC 结果在 `Config` 中有可配置限制。目录缓存在内存中，不可用时不阻塞已安装连接。元数据用于展示，不授予安装权限；Host 在写入前解析所选准确版本并核对配置指纹。

连接使用已有 profile 补丁和修订检查。服务声明的秘密参数及自定义请求头／环境变量值保存在凭据提供方中，补丁只保存引用。移除条目时，仅删除剩余受管配置均未引用的自动生成凭据。备份时一起保存 profile 与凭据。写入失败可能留下未使用的自动生成引用，发布结果不确定时不会自动清除它们。配置或凭据写入未确认时，本次运行会阻止后续市场修改，并持续显示警告。核对两份存储，重启 Genesis 后再编辑。修订过期需要刷新，不覆盖其他窗口的修改。

<a id="model-experience"></a>
## 模型体验

已连接受管工具的准确名称只在操作者 Life 对话中进入有界、带日志的运行上下文。角色可以按需通过已有学习工具学习，无需人工抄写。安装不会把工具标记为已学习、已测试或已授权；学习、工具包启用、QQ 访问与执行守卫仍然独立。当前能力观察和成功调用沿用已有 Genesis 记录路径。

上下文包含工具名，不包含目录或完整工具 schema，占用配置的上下文预算。学习后，常规 MCP 工具声明和结果沿用已有 token 与缓存行为。安装和移除会影响下一次请求的可用工具。目录不提供面向模型的搜索或安装工具。

<a id="limitations"></a>
## 限制

目录安装不支持交互式 OAuth、旧式 SSE、容器、MCPB、自定义软件包源和发布者指定的运行器参数。不支持的条目仍可浏览，但没有安装操作。本地软件包运行器须已安装，本组合包不安装 Node.js 或 Python 运行时。目录可能遗漏鉴权要求，远程服务也可能需要账号或付费。连接失败保留已保存条目，供检查和重试。首页按目录顺序展示，不按热度排序。界面支持中文和英文。
